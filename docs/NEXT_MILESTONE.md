## Focused implementation plan and acceptance criteria

1. Branch from verified main, with no dependency on PR #2. Implement only `doctor [--project <directory>] [--json]`.
2. Report running Node support, selected directory, Git availability/root, sync-lock presence, context initialization, saved-note presence and each output's sync status. Missing Git/repository is a warning when basic offline context can still work; a nested root or blocked validation is an error. Missing context is a setup warning with an init hint. Missing agents are not errors because AgentBridge does not require them.
3. Reuse `projectRoot`, `ProjectGit`, `readText`, `safePath` and `planSync`. Stop context reads when a root/ignore boundary cannot be validated. Never print raw filesystem/Git errors or input text. A failed sync plan produces a bounded diagnostic and a `sync --dry-run` hint, not partial output proposals.
4. Return readable text by default and versioned JSON with stable codes and severity counts. Exit 0 when no error diagnostics exist (warnings may require action); exit 2 for an error. Keep existing status/sync exit semantics unchanged.
5. Make no writes, fixes, backups, locks, agent probes or model calls. Do not evaluate project commands, read lock contents or scan source, home configuration or transcripts. Report lock presence without claiming to know if its owner is alive. Do not attempt to prove filesystem writability by creating a file.
6. Regression tests must cover fresh/healthy projects, all target statuses, state/marker corruption, missing/empty/unsafe context, ignored inputs, unsafe links/hard links, missing Git, missing/nested/canonical versus aliased roots, lock handling and no content/path disclosure. Compare file bytes and inventory before/after diagnostics. Prove unsafe options cannot turn doctor into a writer.
7. Run full tests, typecheck/build on Node 22 and 24, the six-direction simulated workflow and source publication audit. Update the manifest explicitly for new original source/test/docs files. Open one PR targeting main and verify the six-platform CI matrix; do not merge or publish artifacts.
